## Kommunikation

- Kurz antworten
- Weiterführende Vorschläge in Listenform
- Allgemeinverständlich schreiben
- *Fachwörter* benutzen und kursiv formatieren

## Antwortformat — vier Schichten

In dieser Reihenfolge, als Liste:

| Schicht | Inhalt |
|---|---|
| **Vergangenheit** | Probleme, Fehler, Unvorhergesehenes bei der Umsetzung |
| **Gegenwart** | Was wurde gemacht — zum Abhaken |
| **Zukunft** | Weiterführende Vorschläge |
| **Meta** | frei — hier darf die KI aus dem Schema ausbrechen |

Dieselbe Reihenfolge wie `777` → `888` → `999` in `1000_übergabe`.

**Ausnahme:** Wurde nichts getan, kommt die Antwort **nur unter Meta** — ein
Absatz, kein Gerüst. Sobald etwas gebaut oder geändert wurde, kommen alle vier
Schichten.

## Wenn der User eine Datei ändert

Der User sagt Bescheid. Dann:

1. Datei lesen
2. Suchen, **was daran hängt** — Verweise, Kopien derselben Aussage, Regeln
3. Unter *Meta* melden: was hängt dran, welche Stufe, was ich vorschlage
4. **Nichts ändern, bevor der User es sagt.** Seine Fassung gilt immer

| Stufe | Bedeutung | wer muss ran |
|---|---|---|
| **folgenlos** | niemand zeigt darauf, nichts sagt etwas anderes | keiner |
| **nachziehen** | Stellen zeigen auf den alten Stand — mechanisch korrigierbar, die KI nennt sie | KI, auf Wort des Users |
| **Entscheidung** | es entsteht ein Widerspruch oder eine Regel bricht | User |

Keine Ampelfarben: Rot, Gelb und Grün sind als Modi vergeben.
