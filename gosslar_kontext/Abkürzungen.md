# Abkürzungen und Operanden für Schnittmuster-Engine

## Lokale Abkürzungen
| Abkürzung | Bedeutung |
|---|---|
| a | aussen/aeussere/r/s |
| g | gemessen/e/r |
| h | hinten, hintere/r/s |
| i | innen/innere/r/s |
| l | links, linke/r/s |
| m | mittig, mittlere/r/s |
| o | oben, obere/r/s |
| p | paarig, (spiegel-)symmetrisch |
| r | rechts, rechte/r/s |
| s | seitlich, seitliche/r/s |
| t | tiefste/r/s |
| u | unten, untere/s/r |
| v | vorne, vordere/r/s |

## Operanden

| Zeichen | Bedeutung |
|---|---|
| + | plus |
| - | minus |
| : | geteilt durch |
| . | mal in Berechnungen |
| x | mal im Text |
| = | ist gleich |
| <> | ungleich |
| ≙ | entspricht |
| < | kleiner |
| > | groesser |
| % | Prozent |

| Abkürzung | Bedeutung |
|---|---|
| auf | aufdrehen, oeffnen, sperren |
| ueb | uebertragen |
| me | messen |
| zu | zudrehen, schliessen, kneifen |
